# Lumiere Perfumes E-commerce

Professional bright-theme perfume storefront built with React (JSX), Vite, Tailwind CSS, GSAP, Framer Motion, and Lucide React.

## Features

- 24 curated perfume products
- Category filter + search + price sorting
- Client-side pagination
- Product detail pages with routing
- Animated product cards and cart drawer
- Fully functional cart with quantity controls and total pricing
- Persistent cart state using localStorage
- Checkout modal with form validation
- Footer with about/contact/store details
- Clean, component-based code structure

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in terminal (usually `http://localhost:5173`).
